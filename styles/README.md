# Styles Folder

This folder contains standard styles that can be imported into the TSE Demo Builder system. **More styles will be added over time!**

## Purpose

This folder provides a centralized location to:

- Store reusable style definitions for demo configurations
- Maintain a library of pre-built styles for common use cases
- Enable consistent theming and branding across demos
- Allow quick style imports without manual configuration

## Planned Styles

As the library grows, expect styles covering areas such as:

- **Themes**: Light, dark, and custom color themes
- **Layouts**: Preset layout configurations for different demo scenarios
- **Typography**: Font and text styling presets
- **Component Overrides**: Pre-built customizations for embedded ThoughtSpot components

## Usage

To use a style in your demo configuration, import the desired style file and reference it in your configuration JSON. Detailed usage instructions will be provided as styles are added.

## Contributing

When adding new styles to this folder:

- Use descriptive filenames that clearly indicate the style's purpose
- Follow existing naming conventions for consistency
- Include inline comments or documentation within the style file
- Test the style with the Demo Builder before committing

## Current Status

This folder is currently prepared for incoming styles. Check back as new standard styles are added to the library.
